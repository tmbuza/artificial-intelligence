# Artificial Intelligence

**A Practical Path from AI Concepts to a Working Prototype** is a free, complete Complex Data Insights guide. It develops AI problem framing, model capabilities, prompting, retrieval, evaluation, human review, and a guided hackathon. The chapters follow an article-summary example to make design choices and checks concrete. A separate optional CDI Practical provides a more extensive hands-on project.

## Read the guide

The Quarto book is organized in `_quarto.yml`: Foundations (Preface and Chapters 01–03), Modern AI (04–08), Building Responsibly (09–11), AI Hackathon (12–14), and Next Steps (15). The appendix provides reusable worksheets and review records.

Start with the preface and read the chapters in order. Complete the chapter exercises with a task of your own, or follow the article-summary example. The chapter source uses non-executing code fences; rendering the book does not run the displayed Python snippets.

## Render locally

From the repository root, install [Quarto](https://quarto.org/docs/get-started/) and run:

```bash
quarto render
```

The rendered book is written to `docs/`. The book configuration expects `index.qmd`, Chapters 00–15, `99-references.qmd`, `99-appendix.qmd`, `library/references.bib`, the cover image, and `assets/css/cdi.css`.

## Chapter 01 example

Chapter 01 contains a runnable keyword-routing baseline using fictional course policies and synthetic questions. In a checkout containing its accompanying `data/reference/` inputs and `scripts/` programs, use the repository-specific Python environment:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
bash scripts/bash/01-ai-problem-framing.sh
quarto render
```

The script generates the figures cited in Chapter 01 and tables under `results/`. If these support files are not yet present in your checkout, obtain the Chapter 01 package before running or rendering that chapter. The figures and results should be generated by the supplied program; they are not produced by Quarto's code fences.

## Source and output conventions

- Keep executable programs under `scripts/python/` and optional wrappers under `scripts/bash/`, with chapter-number prefixes.
- Store generated figures in `results/figures/` and tables in `results/tables/`.
- Maintain citations in `library/references.bib`; place the references page in `99-references.qmd`.
- Do not commit API keys, private source documents, or reviewer records without appropriate permission.
- Run commands from the repository root unless a chapter specifies otherwise.

The guide explains a complete approach without requiring a paid product. The optional Practical provides structured project files and deeper implementation exercises.
